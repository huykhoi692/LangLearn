# LangLearn

Ứng dụng web đơn giản hỗ trợ học ngôn ngữ với:

- Quản lý từ vựng cá nhân
- Flashcard để tự kiểm tra
- Quiz trắc nghiệm nghĩa từ
- Theo dõi tiến độ học tập
- Lưu dữ liệu bằng LocalStorage

## Chạy dự án

Chỉ cần mở file `index.html` bằng trình duyệt.

Hoặc chạy server tĩnh:

```bash
python3 -m http.server 8000
```

Sau đó truy cập `http://localhost:8000`.
